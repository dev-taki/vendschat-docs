## What every playbook shares

| Building block | Where in the app |
|----------------|------------------|
| Connect channels | **Settings → Workspace → Channels** → **Add Channel** |
| Shared inbox | **Chat** (`/chat`) |
| Organize threads | **Settings → Workspace → Labels** |
| Route work | **Chat** → **Assigned to** (user, **team**, or AI Agent) |
| Fast replies | **Settings → Workspace → Generate Reply** + composer in **Chat** |
| Outbound / campaigns | **Templates** + **Chat** template modal → **Broadcast** tab |
| Customer bots | **AI Agents** — assign in **Chat** recipient panel |
| Performance | **Analytics** (full dashboard **WhatsApp** today) |
| Team access | **Settings → Workspace → Team Members** |
| Multi-brand separation | **Settings → Organization → Workspaces** (marketed on **Advanced**) |

## Plan fit (typical)

| Need | Minimum plan |
|------|----------------|
| WhatsApp + Instagram + Messenger inbox, AI Reply, labels | **Starter** |
| Label **broadcasts**, webhooks, custom AI Agents, integrations | **Growth** |
| Developer **API**, **multiple workspaces**, hosted n8n | **Advanced** |

See [Billing overview](/billing/billing-overview). **Contacts** and **seats** are billed at **organization** level, not per channel.

## Accuracy notes (product today)

These guides reflect the **live dashboard**, not a roadmap:

| Topic | What to tell customers |
|-------|------------------------|
| **Broadcasts** | Create from **Chat** → template composer → **Broadcast** tab (pick labels, optional schedule). The **Broadcast** sidebar page is not the primary create flow yet. **Smart delivery** modes are planned — sends use steady batching today. |
| **HubSpot** | Connect and field-mapping APIs exist; **full contact sync to the inbox panel** is still rolling out — don’t promise live CRM fields in **Chat** until your workspace shows them. |
| **WhatsApp product cards** | Backend can send catalog products; **composer product picker** is not in the dashboard yet. |
| **AI Agent actions** | Toggles (labels, comments, assign team) **guide the bot in instructions** — only **handover** reliably posts an internal note automatically. |
| **Keyword labels** | Configured on each label in **Labels**; applied on **inbound customer text** automatically when rules match. |
| **Co-Admin** | Separate assistant for *your team* — not a customer-facing bot. Ask it live workspace questions or *“how do broadcasts work?”* |

## How Co-Admin should use these docs

1. **Identify persona** — agency vs solo seller vs B2B (table above).  
2. **Quote the copy-paste playbook** at the bottom of the matching doc.  
3. **Point to feature docs** for depth (channels, inbox, templates, broadcasts).  
4. **Use live tools** for *“are we connected?”* — workspace overview, list channels, analytics.  
5. **Clarify plan** before promising broadcasts, API, or multiple workspaces.
