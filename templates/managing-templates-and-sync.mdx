View, search, sync, edit, and delete **WhatsApp message templates** per channel.

**Path:** `/template/whatsapp/list?channelId={channelId}`

**Entry:** **Templates** → channel card → **Manage Templates**

---

## Quick reference

| Task | Control |
|------|---------|
| Open list | **Manage Templates** on WhatsApp card |
| Search | *“Search templates…”* |
| Sync from Meta | **Sync** |
| Export | **Export** (not implemented — toast) |
| View details | Click row or **View** (eye) |
| Edit | **Edit** → `/template/{id}/edit?channelId=` |
| Delete | **Delete** (confirm) — removes from Meta + workspace |
| Create new | **Create Template** (header) |

| Badge | Color | Send allowed? |
|-------|-------|---------------|

| **REJECTED** | Red | No — edit & resubmit |

## Sync from Meta

**Sync** button:

1. Fetches all templates from Meta Graph API for the channel’s WABA  
2. Upserts rows in Vendschat database  
3. Updates status, body, header, footer, buttons  
4. Toast: *“{N} templates synced from WhatsApp.”*

**When to sync:**

- After approving templates in Meta Business Manager outside Vendschat  
- When status looks stale  
- After rejection — confirm updated status  

**Requires:** Active WhatsApp channel with valid credentials and `waba_id` in channel metadata.

## View modal

**View** (eye icon) or click row → **WhatsappTemplateViewModal**

Shows read-only preview of:

- Name, category, language, status  
- Header, body, footer  
- Buttons summary  

Use before editing or sharing with compliance team.

## Edit template

**Path:** `/template/{templateId}/edit?channelId={channelId}`

### Editable fields

| Field | Editable? |
|-------|-------------|
| Name | **No** (locked on edit screen) |
| Category | **No** |
| Language | **No** |
| Header type / content | **Yes** (text header) |
| Body | **Yes** (required) |
| Footer | **Yes** |
| Buttons | Via API/backend — edit UI focuses body/header/footer |

**Save** pushes changes to Meta (when `external_template_id` exists) and updates local DB.

**Note:** Meta may re-review substantive edits — status can return to **PENDING**.

---

## Delete template

**Delete** → confirm:

> *“Delete template "{name}" from WhatsApp and this workspace?”*

Removes from Meta (when linked) and local database. **Cannot undo.**

Threads that already received the template keep history; future sends must use another approved template.

---

## Per-channel scope

Templates belong to a **specific WhatsApp channel** (`channel_id`).

| Implication | Action |
|-------------|--------|
| Multiple WhatsApp numbers | Manage templates **per channel** |
| Wrong channel in URL | Select channel from `/template` hub first |
| Template not found on edit | `channelId` query must match list channel |

---

## Usage metadata

Each template row can track:

- `usage_count` — how often sent  
- `last_used_at` — last send timestamp  

Visible in API/detail; use **Analytics → Template performance** for reply rates.

---

## Troubleshooting

| Issue | Fix |
|-------|-----|
| Sync failed | Check WhatsApp channel active; token valid; WABA linked |
| Edit 404 | Verify `channelId` + template id |
| Approved in Meta but Pending here | Run **Sync** |
| Can’t send in Chat | Status must be **APPROVED** |
| Delete failed | Template may be in use; check Meta errors |
