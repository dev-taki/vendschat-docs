Connect **WhatsApp**, **Facebook Messenger**, and **Instagram Direct** to a **workspace** so your team shares one **Chat** inbox.

**Who this is for:** Owners and admins connecting Meta channels, and Co-Admin answering *“Where do I add WhatsApp?”*

**Primary path:** **Settings → Workspace → Channels** → `/settings/workspace/channels`

## Product snapshot

| Topic | Behavior |
|-------|----------|
| **Self-serve connect** | WhatsApp, Messenger, Instagram only |
| **Catalog** | `/settings/workspace/channels/catalog` — **Add Channel** from list |
| **Manage** | Channel card → setup with `?channelId=` |
| **Status on list** | **Not shown** on channel cards — open **Manage** to see `pending` / `active` / `disconnected` / `error` |
| **Disconnect** | **No dashboard button** — backend API exists; customers **reconnect** via **Manage** or contact support |
| **Multiple numbers** | **Multiple WhatsApp** (and Messenger/IG) channels per workspace supported |
| **Workspace scope** | Channels do **not** copy when you create a new workspace |
| **Billing** | Channels included on paid plans; contacts/seats at **organization** level |

## Routes

| URL | Purpose |

| `/settings/workspace/channels/messenger/setup` | Messenger wizard |
| `/settings/workspace/channels/instagram/setup` | Instagram wizard |
