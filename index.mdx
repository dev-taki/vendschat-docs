## Product map

| Piece | What it does | Where |
| --- | --- | --- |
| **Chat** | Shared inbox — assign, label, resolve | Sidebar **Chat** |
| **Channels** | WhatsApp, Messenger, Instagram | **Settings → Workspace → Channels** |
| **AI Agents** | Customer-facing bots + handoff | **AI Agents** |
| **Co-Admin** | Internal helper. Never sends customer messages | Co-Admin panel |
| **Templates** | Meta-Approved WhatsApp templates | **Templates** |
| **Broadcast** | Campaigns to a label or CSV | **Broadcast → New broadcast** |
| **Integrations** | Agent Skill, Lovable, MCP, Zapier, Make, n8n | Sidebar **Integrations** |
| **Analytics** | Sent, delivered, read | **Analytics** |
