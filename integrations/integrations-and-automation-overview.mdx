Connect Vendschat to the tools you already use — CRM, workflow automation, custom backends — without replacing your shared **Chat** inbox.

**Who this is for:** Ops leads, developers, and anyone asking Co-Admin *“How do I connect Zapier?”*, *“Where are webhooks?”*, or *“Do we have an API?”*

**Hub path:** Sidebar **Integrations** (`/integrations`) for Agent Skill, Lovable, MCP, Zapier, Make, n8n, HubSpot. Webhooks, API keys, and REST API stay under **Settings → Workspace**.

**Search:** *“Search integrations…”* field at top of catalog.

**Note:** Catalog cards show connection status and counts. Some **Connect** / **Manage** actions may route to dedicated setup flows as each integration is fully wired in the product.

## How integrations relate to Chat

| Layer | Role |
|-------|------|
| **Chat** | Humans (and AI Agents) reply to customers |
| **Webhooks** | Push real-time **events** to your URLs (Make, Zapier, n8n, custom) |
| **HubSpot** | Sync **contacts** and field mappings with CRM |
| **REST API** | Pull/push data from your backend (threads, messages, channels) |
| **n8n / Make / Zapier** | Orchestrate multi-step automation using webhooks + API |

Integrations do **not** replace **Chat** — they extend what happens when messages arrive or get sent.

## Webhooks (real-time events)

When something happens in Vendschat, notify your HTTPS endpoint.

**Path:** **Settings → Workspace → Webhooks** (`/settings/workspace/webhooks`)

**UI sections:**

- **Event destinations** — table of webhook URLs  
- **Add destination** · **Import**  
- Per row: Destination URL, Name, **Active** / **Disabled**, event count, **Edit** / **Enable** / **Disable** / **Delete**  
- **Filter by Channel** · Search

## API Keys & REST API

**API Keys:** **Settings → Workspace → API Keys** — create named keys, optional expiry, revoke/delete.

**REST API docs in app:** **Settings → Workspace → REST API**

- Base URL shown: `https://api.vendschat.com/v1`  
- Auth: `Authorization: Bearer YOUR_API_KEY`  
- Sections: Authentication, Messages, Users, Channels, Webhooks  
- Rate limit note: 1000 requests/hour per key  

Deep dive: [API keys & REST API](/integrations/api-keys-and-rest-api)

## n8n automation

Two ways to use n8n with Vendschat:

| Mode | Path | Plan |
|------|------|------|
| **Self-serve / external n8n** | Connect via **Webhooks** + Vendschat triggers | Growth+ |
| **Hosted n8n instance** | Sidebar **n8n** (`/n8n`) → **Generate Free Instance** | **Advanced** (managed specs in billing docs) |

**n8n page** (`/n8n`) — *“Start automating with n8n”*

| Field | Purpose |
|-------|---------|
| Instance Name | Unique subdomain (e.g. `my-company.n8n.cloud`) |
| Region | US East, Europe (Frankfurt), Asia (Singapore) |
| Admin Email | Instance admin |
| **Generate Free Instance** | Provision hosted instance |

**Free tier highlights (in UI):** 20 active workflows · 1,000 executions/month · 200+ nodes · community support.

Deep dive: [n8n, Zapier & Make](/integrations/n8n-zapier-make)

## Security habits

- Rotate **webhook signing secrets** when staff leave  
- Subscribe only to **events** you actually process  
- Use **HTTPS** endpoints for webhooks in production  
- Store **API keys** in secrets managers — never in **Chat** with customers  
- Test with staging URLs before production  
- Revoke unused API keys promptly
